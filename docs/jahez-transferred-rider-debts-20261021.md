# جاهز — المديونيات المرحلة على المناديب وتفاصيل الاعتماد

تعديل 21 أكتوبر 2026 في كود الباك إند. يلزم نشر الـ API وتحديث الواجهة؛ لا توجد واجهة التشغيل الرئيسية داخل هذا المستودع.

التسليم الكامل للواجهة باللغة الإنجليزية، مع الشاشات وتسلسل الطلبات والأمثلة والصلاحيات والأخطاء واختبارات القبول: [Full frontend handoff](jahez-transferred-debts-full-frontend-handoff-20261021.md).

## إلغاء البلوك

وجود مديونية جاهز مرحلة غير مسددة لا يوقف تشغيل المندوب أو إسناده على كيتا أو شيفز أو نينجا. تسري القاعدة على الديون القديمة والجديدة عند نشر النسخة. لا يتم حذف الدين أو اعتباره مسدداً، ولا تتغير حالات الإيقاف المستقلة المسجلة للحسابات أو الإسنادات. إشعارات الترحيل والسداد أصبحت مالية، دون تعليمات إيقاف.

## مبالغ طلب المدير

الإدخال الحالي `net` يظل صافي/مديونية داشبورد جاهز الذي يدخله الموظف يدوياً بإشارته. النظام يحسب العمولة المستحقة غير المسددة، والإجمالي = `net + commission`. لا يتم جلب المديونية الإدارية أو رسوم الحساب ودمجها تلقائياً.

تتضمن استجابة `POST /api/jahez/v2/requests` واستجابة القرار حقل `amounts`، كما تتضمنه كل نتيجة من `GET /requests` و`request.amounts` في `GET /requests/{id}`:

```json
{
  "amounts": {
    "dashboardDebt": 1000,
    "commission": 150,
    "total": 1150
  }
}
```

اعرض للمدير: «مديونية داشبورد جاهز المدخلة»، «العمولة المستحقة»، «إجمالي الترحيل»، مع المندوب والحساب والفترة والسبب. `amounts=null` للطلبات التي لا ترتبط بعملية تصفية. القيم في استجابات القراءة تتبع العملية المرتبطة الحالية، بينما دليل القرار محفوظ في `decisions[].decisionJson`؛ اعتماد الترحيل هو الذي يثبت الالتزام، وليس إنشاء الطلب.

## قائمة المناديب المدينين

`GET /api/jahez/v2/riders/transferred-debts?page=1&pageSize=50`

الصلاحية: `jahez.read` في نطاق جاهز. الاستجابة `Page<RiderTransferredDebtSummary>`؛ يظهر كل مندوب مرة واحدة، وتجمع ديونه المرحلة غير المسددة فقط:

```json
{
  "items": [{
    "riderProfileId": "GUID",
    "userRider": { "nameAr": "اسم المندوب", "iqamaNo": "رقم الإقامة" },
    "unpaidDebtCount": 2,
    "outstandingAmount": 1150,
    "amounts": { "dashboardDebt": 1000, "commission": 150, "total": 1150 }
  }],
  "page": 1,
  "pageSize": 50
}
```

المثال يختصر حقول هوية المندوب. تحتفظ القائمة بالمندوب المؤرشف والتزامات السجل التاريخي. إذا فُقدت بيانات العملية الأصلية يظهر `amounts=null` مع بقاء `outstandingAmount` الفعلي؛ لا تعرض التفاصيل المفقودة كأصفار.

`GET /api/jahez/v2/riders/{riderId}/transferred-debts?page=1&pageSize=50` يعيد تفاصيل الديون غير المسددة لهذا المندوب، بنفس عقد `TransferredDebtRow` الحالي، شاملاً الحساب والإسناد القديم و`sourceOperation.net/commission/remaining`. حد الصفحة 100، والنتائج لا تشمل ديوناً مسددة أو محذوفة. قائمة `GET /transferred-debts` القديمة تظل للسجل الكامل، وإجراء سداد الدين الواحد يظل متاحاً.

## سداد جميع المبالغ المرحلة على المندوب

`POST /api/jahez/v2/riders/{riderId}/transferred-debts/repayment`

يتطلب `Idempotency-Key` وصلاحيتي `jahez.transferred-debt.repay` و`jahez.money.receive` في نطاق جاهز.

```json
{
  "expectedAmount": 1150,
  "fund": 1,
  "reference": "رقم إيصال القبض الفعلي",
  "reason": "سداد كامل المديونية المرحلة"
}
```

أرسل `expectedAmount` من `outstandingAmount` الظاهر للمستخدم؛ هو شرط تحقق وليس مبلغ سداد حر. يعاد 409 إذا تغير الإجمالي أو لم توجد ديون مفتوحة. جهة القبض للسداد هنا هي الخزنة `fund=1` وفق سياسة سداد الدين المرحل الحالية؛ لا يختار العميل البنك أو بترو آب. المرجع مطلوب بحد 500 حرف والسبب مطلوب بحد 2000 حرف.

السداد كامل فقط، ويسجل حركة قبض مستقلة لكل التزام مع نفس المرجع وربطها بالدين الأصلي وملكيته في الخزينة. يحدث ذلك داخل معاملة واحدة؛ فشل أحد الالتزامات يلغي الإجراء كله. الاستجابة:

```json
{
  "riderProfileId": "GUID",
  "paidAmount": 1150,
  "paidDebtIds": ["GUID", "GUID"],
  "remainingAmount": 0
}
```

إعادة نفس الطلب بالمفتاح نفسه ترجع النتيجة السابقة دون قبض مكرر؛ إعادة المفتاح ببيانات مختلفة تعيد 409. بعد النجاح حدّث القائمة وتفاصيل المندوب وحركات الخزينة. يصبح رصيد **المديونيات المرحلة** صفراً ويختفي المندوب من هذه القائمة؛ هذا لا يصفر رسوماً أو ديوناً إدارية أو فترات «سحب دون تصفية» منفصلة.

لا تستخدم هذا الإجراء لإسقاط الدين دون تحصيل فعلي. «سحب دون تصفية» لا ينشئ ديناً مرحلاً، ولذلك لا يدخل هذه القائمة تلقائياً؛ تظل تصفيته مرتبطة بفترة المندوب القديم.
